# 📝 Todo List App

A simple Todo List application built with React that allows users to create, edit, complete, and delete tasks. The application uses Context API for state management and Local Storage to persist data between sessions.

## 🚀 Features

* Add new todos
* Edit existing todos
* Delete todos
* Mark todos as completed or incomplete
* Automatically save todos in Local Storage
* Responsive and user-friendly interface
* Global state management with Context API
* Custom React Hook implementation

## 🛠️ Tech Stack

* React
* Context API
* Custom Hooks
* Tailwind CSS
* JavaScript (ES6+)
* Local Storage
